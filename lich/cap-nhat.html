HOW TO UPDATE / CÁCH CẬP NHẬT

3 bước
mỗi tuần

  1. Mở Google SheetsOpen the Google Sheet

    Đăng nhập Google và mở bảng lịch lớp Omega Pilates.

  2. Sửa lịch tuầnEdit the weekly schedule

    Giữ cấu trúc hàng KHUNG GIỜ, các cột ngày và nội dung lớp. Tên lớp nên chứa Mat Pilates, Reformer Pilates hoặc Wallunit Pilates.

  3. Lưu bảng tínhSave the spreadsheet

    Chỉ cần lưu Google Sheets. Không cần sửa HTML hay deploy GitHub; trang /lich sẽ tự đọc dữ liệu mới ở lần tải tiếp theo.

Google Sheets / Bảng điều khiển lịch

Hãy giữ quyền chia sẻ ở mức Anyone with the link → Viewer để website có thể đọc lịch. Chỉ những người được bạn cấp quyền Editor mới có thể sửa bảng.

Keep sharing set to Anyone with the link → Viewer so the website can read the schedule. Give Editor access only to studio staff.
